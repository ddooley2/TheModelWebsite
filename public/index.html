TRANSPARENCY

Methodology

Score-first

The system predicts each team’s final score. Projected spread and total are arithmetic consequences, rather than separately optimized betting targets.

Pre-kickoff only

Inputs use earlier game results, point-in-time opponent-adjusted ratings, preseason Elo, talent, recruiting, rest, week, and neutral-site status.

Market firewall

Opening and current lines are retrieved after predictions are created. They are displayed for comparison and never enter model fitting or score prediction.

Walk-forward evaluation

Each season is predicted by a model trained only on preceding seasons. Seasonal performance and feature coverage are published in the data-quality section.
